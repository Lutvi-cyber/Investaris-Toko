Program Python untuk mengelola inventaris toko alat tulis: membuat,
menambah, membaca, menganalisis, melaporkan data lewat file, dan mengujinya.

## Cara menjalankan
cd bagian_b
python main.py

## Struktur
- toko/validasi.py: validasi data
- toko/processing.py: class Barang dan Inventaris
- toko/fileio.py: baca/tulis/tambah file
- toko/testing.py: unit test
- main.py: file utama
